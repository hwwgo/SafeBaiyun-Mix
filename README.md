## 📱 功能特性

### 🔑 核心功能
- 🚪 **离线开门** — 无需网络，本地蓝牙 BLE 连接即可开门
- 📱 **多门禁管理** — 支持添加、编辑、删除多个门禁设备，自定义名称（如"家里"、"公司"）
- 🎯 **快捷方式** — 桌面快捷方式一键开门，无需打开 App

### 🚀 增强功能（Mix 独有）
- 🔄 **一键轮询** — 自动依次尝试所有勾选的门禁，成功即停
- ☑️ **勾选与排序** — 每个门禁独立勾选，上下拖动调整顺序
- 📲 **二维码导出** — 将所有门禁配置编码为二维码，支持保存到相册或分享
- 📷 **二维码导入** — CameraX + ML Kit 实时扫码，支持「替换全部」或「追加到现有」
- 🖼️ **三键快开部件** — 特大号桌面小部件，同时展示 3 个门禁，每个一键解锁
- ⚙️ **个性化设置** — 超时时间、轮询间隔、UI 延迟均可自定义，一键恢复默认
- 📊 **开锁实时进度** — 显示连接、发现服务、读取挑战码、写入指令等每一步
- 🔄 **旧数据迁移** — 自动将原版单门数据迁移为多门格式，升级无忧
- 🔧 **自动构建发布** — 推送标签即可通过 GitHub Actions 自动构建并发布签名 APK

### 🎨 UI 优化
- 卡片式布局：圆角 12dp，柔和阴影
- 横向信息排列：左文右按钮，信息清晰
- 动态字号：长名称自动缩小，最多显示 2 行
- 开锁按钮：88dp 宽度，完整显示“开锁”文字
- 复选框 + 排序按钮：小巧精致，不占空间
- 蓝牙状态检查：未开启时友好提示，不再闪退

## 📖 使用方法

1. 提取门禁的 MAC 地址及加密密钥，[获取方式](extract.md)
2. 点击右上角编辑按钮，添加门禁并填入 MAC 和 Key，保存
3. 点击对应门禁的开门按钮即可

> 💡 支持添加多个门禁，每个可自定义名称便于区分。

### 勾选与排序
- 每个门禁卡片左侧有复选框，只有勾选的门禁参与“一键轮询”
- 点击卡片右侧的上下箭头调整顺序，轮询时按此顺序依次尝试

### 一键轮询
1. 勾选需要尝试的门禁
2. 点击“一键轮询开锁 (N/M)”按钮
3. App 自动依次尝试，成功即停

## 📲 二维码同步

### 导出配置
1. 在主界面底部点击「导出配置」
2. 自动生成包含所有门禁配置的二维码
3. 可保存到相册或直接分享给他人

### 导入配置
1. 在主界面底部点击「扫描导入」
2. 对准二维码即可自动识别
3. 选择导入方式：
   - **替换全部** — 清除现有配置，使用扫码数据
   - **追加到现有** — 保留现有配置，将扫码数据添加到末尾

### 二维码格式
导出的二维码数据格式为 `SBY|<Base64>`，其中 Base64 解码后为门禁列表的 JSON 序列化（`kotlinx.serialization`），与 `DoorDevice` 数据模型对应。第三方工具可据此解析。

## 🖼️ 桌面小部件

本应用提供三种尺寸的桌面小部件（基于 AndroidX Glance，需 Android 12+）：

| 尺寸 | 说明 |
|:---|:---|
| 中号 | 紧凑横条，显示"白云通"+ 一键解锁按钮 |
| 大号 | 带广州塔插图 + 一键解锁按钮 |
| **特大号** | 三键快开，同时展示 3 个门禁，各自独立解锁（Mix 独有） |

> 在桌面长按空白处 → 添加小部件 → 选择「平安回家」即可。

## ⚙️ 设置页面

1. 点击右上角齿轮图标 ⚙️
2. 调整以下参数：
   - **单次开锁超时**（默认 10 秒）
   - **轮询间隔**（默认 0.5 秒）
   - **结果展示延迟**（默认 1.5 秒）
   - **状态复位延迟**（默认 2 秒）
3. 点击“恢复默认”一键重置所有设置为默认值
