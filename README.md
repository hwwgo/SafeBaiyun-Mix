🔓 SafeBaiyun Mix

基于 SafeBaiyun 和 SafeBaiyun-Mix 的二次开发版本

更多门 · 更快传 · 更智能 · 更好用

广州市白云区蓝牙门禁「平安回家」离线版本。

本项目在原版 SafeBaiyun 的基础上，由 yotong-max/SafeBaiyun-Mix 进一步扩展，并在此基础上继续增加和优化了多门禁管理、自动轮询、开锁状态反馈、参数调节以及 UI 交互等功能。

无需网络连接，只需门禁 MAC 地址和加密 Key，即可通过手机蓝牙 BLE 离线开门。

🆕 本项目特色功能

🔄 一键轮询开锁

这是本项目比较核心的增强功能。

当你有多个门禁，但不确定当前所在位置对应的是哪一个门禁时，可以选择多个门禁进行轮询。

例如：

· 🏠 家里

· 🏢 公司

· 🚪 小区东门

· 🚪 小区西门

勾选需要尝试的门禁后，点击 一键轮询开锁。

程序会按照门禁排序依次尝试：

```
门禁 1
  ↓
失败
  ↓
门禁 2
  ↓
失败
  ↓
门禁 3
  ↓
成功 🎉
  ↓
立即停止
```

一旦某个门禁成功开锁，就会立即停止继续尝试。

---

☑️ 门禁勾选

每个门禁都可以单独控制是否参与轮询。

例如：

```
☑ 家里
☑ 公司
☐ 小区东门
☑ 小区西门
```

只有勾选的门禁才会参与「一键轮询」。

这样可以避免删除暂时不用的门禁，同时保留完整配置。

---

↕️ 门禁自由排序

可以自由调整门禁的轮询顺序。

例如：

```
1. 家里
2. 公司
3. 小区东门
4. 小区西门
```

调整后：

```
1. 小区西门
2. 家里
3. 公司
4. 小区东门
```

轮询时会按照当前排序依次尝试。

因此可以把最常用、最可能成功的门禁放在前面，减少等待时间。

---

📊 开锁实时进度

相比单纯显示「开锁成功 / 失败」，本项目增加了更加详细的开锁过程反馈。

例如：

```
正在连接门禁...
       ↓
连接成功
       ↓
正在发现服务...
       ↓
服务发现成功
       ↓
正在读取挑战码...
       ↓
挑战码读取成功
       ↓
正在发送开锁指令...
       ↓
开锁成功 🎉
```

这样在开锁失败时，也更容易判断问题出现在哪一个阶段。

---

⚙️ 开锁参数自定义

新增设置页面，可以根据不同手机、蓝牙环境以及门禁设备情况调整参数。

目前支持：

参数 默认值 作用
单次开锁超时 10 秒 单个门禁最大尝试时间
轮询间隔 0.5 秒 不同门禁之间的等待时间
结果展示延迟 1.5 秒 开锁结果展示时间
状态复位延迟 2 秒 开锁状态恢复时间

如果你的手机蓝牙连接速度较慢，可以适当增加超时时间。

如果多个门禁连续轮询时出现连接不稳定，也可以尝试调整轮询间隔。

同时提供 「恢复默认」 按钮，可以一键恢复所有参数。

📱 多门禁管理

支持同时保存多个门禁设备。

每个门禁可以单独设置：

· 名称
· MAC 地址
· 加密 Key
· 是否参与轮询
· 轮询顺序

例如：

```
🏠 家里
MAC: XX:XX:XX:XX:XX:01

🏢 公司
MAC: XX:XX:XX:XX:XX:02

🚪 小区东门
MAC: XX:XX:XX:XX:XX:03
```

可以随时添加、编辑、删除。

---

📲 二维码配置同步

支持将门禁配置导出为二维码。

导出

1. 点击「导出配置」
2. 自动生成二维码
3. 可以保存到相册
4. 也可以直接分享

导入

打开「扫描导入」，扫描二维码即可恢复门禁配置。

支持两种模式：

· 替换全部：清除当前门禁配置，使用二维码中的配置。
· 追加到现有：保留当前配置，将二维码中的门禁追加到列表。

🖼️ 桌面小部件

支持多种尺寸的 Android 桌面小部件。

尺寸 功能
中号 快速开门
大号 广州塔主题 + 快速开门
特大号 同时显示 3 个门禁并快速开门

特大号三键小部件可以直接展示三个常用门禁：

```
┌──────────────────────┐
│  家里       🔓 开锁  │
│  公司       🔓 开锁  │
│  小区       🔓 开锁  │
└──────────────────────┘
```

无需打开 App 即可快速开门。

🔄 旧数据自动迁移

如果你之前使用的是旧版 SafeBaiyun，本项目支持将原来的单门禁数据自动迁移到新的多门禁数据结构。

无需重新手动录入。

🔐 隐私与数据安全

本项目的核心开门流程采用本地蓝牙 BLE 通信。

正常开门过程中：

· 不需要联网
· 不依赖远程服务器
· 门禁配置保存在本地
· MAC 地址和 Key 不上传服务器

⚠️ 请妥善保管你的门禁 MAC 地址和加密 Key。

二维码导出的配置包含门禁相关信息，请不要将包含真实门禁配置的二维码公开发布或分享给不可信的人。
